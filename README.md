# qml-adversarial-MNIST

Code is build upon https://github.com/Hon-Hai-Quantum-Computing/QuantumTrain
## Setup
Install Miniconda manually from https://docs.conda.io/en/latest/miniconda.html



Create conda enviroment with python
```bash
conda create -n qcnn_mnist python=3.10
```

(Don't need if ran last step) Python install within the conda enviroment
```bash
conda install -n qcnn_mnist python=3.10 pip -y
conda deactivate
conda activate qcnn_mnist
```

Verify python installment
```bash
python --version
python -m pip --version
```

Installing dependencies
```bash
python -m pip install -r requirements.txt
```
